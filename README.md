### 🧩 Featured Projects

#### 🛒 **Loop — Full-Stack E-Commerce Platform**
A production-grade shopping platform engineered for real-world store operations, complete with dedicated user and admin dashboards.
* **The Build:** React-based frontend integrated with a Node.js/Express REST API.
* **The Architecture:** Robust MongoDB data modeling (Users, Products, Orders, Cart, Wishlist).
* **The Features:** Secure authentication/authorization, real-time updates, and an intensive admin panel for holistic user and product management.

#### 📈 **Fantasy Exchange — Real-Time Crypto Trading + AI Platform**
A complete, enterprise-grade FinTech trading ecosystem powered by artificial intelligence.
* **The Build:** React + Tailwind UI connected to a secure Node.js backend handling authorization and trading APIs.
* **The Architecture:** FastAPI microservices driving live price fetching and RAG-based AI market analysis pipelines. Dockerized and deployed on AWS via Jenkins CI/CD.
* **The Features:** Internal wallets protected against race conditions, duplicate debit prevention using Redis + NGINX, and an embedded AI-driven trading assistant analyzing live and historical market data.
