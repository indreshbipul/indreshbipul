### 🧩 Featured Projects

#### 📈 **Fantasy Exchange — Real-Time Crypto Trading + AI Platform** *(Under Development)*
A comprehensive real-time crypto trading and AI-powered analytics platform featuring a user dashboard, internal wallet, and AI-driven trading assistance.
* **Frontend:** Built using **React.js** and **Tailwind CSS**.
* **Backend & AI:** Developed with **Node.js** to handle secure user authentication, authorization, and trading APIs. Integrated **FastAPI** microservices to fetch live crypto prices and implemented **RAG-based AI pipelines** to generate intelligent trading insights using live and historical market data.
* **Architecture:** Utilized **Redis** and **NGINX** for low-latency data delivery and to protect idempotency in wallet transaction services (ensuring duplicate requests do not result in multiple debits). Efficient storage of user and transaction records is handled by **MongoDB**.
* **DevOps:** The entire system is containerized using **Docker** and deployed on **AWS** using a robust **Jenkins CI/CD** pipeline to automate build, test, and deployment processes.

#### 🛒 **Loop — Full-Stack E-Commerce Web Application**
A MERN-stack shopping platform with robust authentication and SKU-driven product management.
* **Tech Stack:** React, Node.js, Express, MongoDB.
* **Features:** Secure JWT-based authentication. Core features include product browsing, cart, and wishlist (completed). The admin panel and order management system are currently under development.
* **Live Deployment:** [Check it out here](https://loop-shopping.netlify.app/)
